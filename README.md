# dummy-restaurant-order-analysis
Analysis of a dummy restaurant orders using MySQL

In the following repository, I analyzed the customer data of a dummy restaurant that has diverse menu offerings and serves generous portions using MySQL. In here, I wanted to see which menu items are doing well/not well and what the top customers seem to like best.

I dug into the restaurant database, which was made by the SQL script file, _create_restaurant_db.sql_. The database consists of two tables, namely the _menu_items_ table and _order_details_ table. Data of both tables came from the csv files with the same name (_menu_items.csv_ and _order_details.csv_). As reference, the _restaurant_db_data_dictionary.csv_ contains information about the fields on both tables.

You can check my analysis of the data in the SQL script file, _restaurant_order_analysis.sql_. 
Thank you

Note: The data and the whole project comes from MavenAnalytics. All thanks to them.
